# Student Management System

A basic PHP-based student management system.

## Features
- Add new students
- View all students
- Delete students

## Technologies
- HTML
- CSS
- PHP
- MySQL

## Setup
1. Install XAMPP
2. Copy files to `htdocs` folder
3. Create database `student_db`
4. Import SQL table
5. Access via `localhost`
